# Gesture-Vision-Computer-Vision-Based-Hand-Gesture-Detection
GestureVision is a real-time Al-powered camera application that allows users to control camera filters using only hand gestures

Using hand tracking with MediaPipe and image processing with OpenCV, the system can detect finger touch gestures and switch filters without touching the keyboard or screen.
## Features:

Real-time hand gesture recognition

Touchless filter switching

Thermal, Sketch, Vintage, Gray, and Invert filters

Multi-hand tracking support

High-resolution live camera processing

## Technologies Used:

Python |

MediaPipe |

## Gestures:

-> Left Thumb + Left Index Finger →

Next Filter

-> Right Thumb + Right Index Finger →

Previous Filter
